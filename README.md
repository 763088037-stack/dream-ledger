# 梦幻收益管家

记录每天几个号的收益，算清这一天的净收入和每小时收益。

## 怎么打开

双击 `index.html`，浏览器会直接打开。

## 现在是什么版本

**v0.1** —— 静态页面。

- 页面上的五个角色、收入、耗时都是手写在 HTML 里的
- 总收入、总耗时、时薪是人工算好后写进去的

## 接下来要做什么

- v0.2：加一个录入表单，能自己添加和删除记录，数据存在浏览器里
- v0.3：换成 React，加图表，看出哪个任务时薪最高
- v0.4：加后端，手机和电脑看到同一份数据

## 数据说明

收入单位是「万梦幻币」，耗时单位是分钟。

时薪 = 总收入 ÷ 总时长，当前为 88 ÷ 7.75 ≈ 11.4 万/小时。
